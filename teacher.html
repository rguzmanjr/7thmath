Leaderboards

    Post to the student leaderboard

    Posts the top 10 for every game (all time, every question set, one spot per student) to the leaderboard students open from the hub. Hidden names stay off. Students see names, scores, accuracy and the question set, never the codes. The site takes a minute or two to show the new board.

    How to get the key (one time)
    1. Open GitHub's new fine-grained token page.
    2. Name it Arcade leaderboard, set Resource owner to your GitHub account (yours), and pick an expiration (up to a year).
    3. Under Repository access, choose Only select repositories and pick the site’s repository (the one this page lives in).
    4. Under Permissions, set Contents to Read and write.
    5. Click Generate token, copy it, paste it above and click Save.

    The key stays in this browser only. It can change files in the site’s repository and nothing else. Without it, use Download file instead and upload the file to the repo's data folder on github.com.
